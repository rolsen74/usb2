# PL2303 and CDC ACM USB Serial

`usb2serial.device` exposes the PL2303 adapter with USB vendor and product
ID `067b:2303` and CDC ACM virtual serial ports to AmigaOS 4 applications.
The USB stack creates the device at boot. PL2303 and CDC ACM share its
unit list and use the lowest free number, starting at 0. Unplugging an
adapter removes its unit. Reopen the device to use a replacement adapter.

`cls_CDCACM.Class` matches the CDC ACM control interface (`02/02`).
The driver finds and claims the associated CDC data interface (`0A`)
and uses its bulk IN and OUT endpoints. Line coding, break, and serial
state use the controls and endpoints provided by the device.

## Build and install

```sh
make -C Drivers/Serial/PL2303
```

Install `usb2.kmod` 1.21 or later and copy `ser_PL2303.Driver`, `ser_PL2303.Class`,
and `cls_CDCACM.Class` from the same archive to `LIBS:USB2/`. Reboot with the
updated module and select `usb2serial.device` in the serial application.
The first adapter is unit 0.

CDC Ethernet and other CDC subclasses require their own drivers.
Operation with a physical adapter remains unverified.
