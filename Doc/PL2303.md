# PL2303 USB Serial (Untested)

`usb2serial.device` exposes the PL2303 adapter with USB vendor and product
ID `067b:2303` to AmigaOS 4 serial applications.

## Build and install

```sh
make -C Drivers/Serial/PL2303
```

Copy `Drivers/Serial/PL2303/bin/PL2303.Driver` and
`Drivers/Serial/PL2303/PL2303.Class` to `LIBS:USB2/`. Select
`usb2serial.device` in the serial application. The driver cross-compiles.
Operation with a physical adapter remains unverified.
