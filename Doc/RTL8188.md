# RTL8188EU USB Wi-Fi

`usb2rtl8188.device` is an experimental SANA-II Soft-MAC driver for Realtek
RTL8188EU USB adapters. It matches USB vendor and product IDs `0bda:8179`,
`07b8:8179`, and `2357:010c`. The driver supports 2.4 GHz infrastructure mode
on channels 1–11. Transmit currently uses 1 Mbps CCK and requires a valid
transmit power calibration value from the adapter.

## Build and install

Build from the repository root with the AmigaOS 4 cross-compiler.

```sh
make -C Drivers/Ethernet/RTL8188
```

1. Start AmigaOS 4 with `usb2.device` loaded.
2. Copy `Drivers/Ethernet/RTL8188/bin/usb2rtl8188.device` to
   `DEVS:Networks/`. In the distribution archive, the file is at
   `usb2/Devs/Networks/usb2rtl8188.device`.
3. Copy `rtl8188eufw.bin` and `rtl8188eufw.licence` to
   `DEVS:Firmware/`. The archive includes both files in
   `usb2/Devs/Firmware/`. They are also available in
   `Drivers/Ethernet/RTL8188/Firmware/`.
4. Connect the adapter and run the bundled wireless manager.

## USB2WirelessManager

The bundled [USB2WirelessManager](USB2WirelessManager.md) scans for a named
network and joins open, WPA-Personal (TKIP), WPA2-Personal or WPA3-Personal networks. Its guide covers building,
installing, commands, and the order for starting the TCP/IP interface.

The library's [public interface](../inc_Public/usb2wpa2.h) is available to
other AmigaOS 4 clients. Use one active session per task, and create, process,
and destroy it on that task. Pass it EAPOL payloads from the associated BSSID,
apply the returned key actions, send the reply, and enable normal traffic when
the library returns the authorization flag.

If the serial log shows `S2_CONFIGINTERFACE error 0` with `AID 0, online 0`,
the interface has its station address and is waiting for Wi-Fi association.
Use the manager's Shell output and the driver's `S2_SETOPTIONS` messages
to diagnose this stage.

The unmodified firmware is from the [Linux firmware repository, 20260309
release](https://kernel.googlesource.com/pub/scm/linux/kernel/git/firmware/linux-firmware/+/refs/tags/20260309/rtlwifi/).
Its [Realtek license](../Drivers/Ethernet/RTL8188/Firmware/rtl8188eufw.licence)
is included alongside it.

## Wireless security and validation

- The manager can join open, WPA-Personal (TKIP), WPA2-Personal and WPA3-Personal networks.
  The supplicant installs pairwise and group keys through `S2_SETKEY`.
- The bundled WPA2 library handles the initial four-way handshake and group
  key rotation. The WPA3 library handles SAE and WPA3 key exchange. Driver
  version 1.2 adds protected management frames using CCMP-128 and BIP-CMAC-128.
  WPA3 was tested on RTL8188EU hardware.
- The driver implements TKIP data encryption and local Michael MIC
  countermeasures. Use the separate WPA library for legacy WPA/TKIP pairwise
  and group-key exchange. WPA/TKIP association was tested on RTL8188EU. Authenticated
  EAPOL MIC failure reports, pairwise rekeying and enterprise authentication
  are outside this version.
- The AmigaOS 4 cross-build succeeds. Host I/O mocks and known-answer
  vectors covered CCMP, TKIP, and replay rejection. One `0bda:8179` adapter
  joined a WPA2 network on channel 5 and passed web traffic on AmigaOS 4.
  Other adapters and long-running stability remain unverified.
