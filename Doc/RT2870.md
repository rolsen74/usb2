# RT2870 USB Wi-Fi

`eth_RT2870.Driver` supports 2.4 GHz channels 1 through 13 on ASIC revision
`0x28600101` with a 2T2R RF2820 configuration. The class matches these IDs.

| USB ID | Adapter | Amiga hardware validation |
| --- | --- | --- |
| `07D1:3C09` | D-Link DWA-140 rev B1 | WPA3 connected on an AmigaOne X5000/20 |
| `07D1:3C13` | D-Link DWA-130 rev B | Pending |
| `0411:00E8` | Buffalo WLI-UC-G300N | Pending |
| `0B05:1761` | ASUS USB-N11 | Pending |
| `14B2:3C06` | Conceptronic C300RU v1 | Pending |
| `7392:7718` | Edimax EW-7718Un | Pending |

The serial log reports the USB ID and ASIC revision at probe and reports
unsupported revisions or RF configurations before the unit registers.
[Linux Wireless device table](https://wireless.docs.kernel.org/en/latest/en/users/drivers/rt2800usb/devices.html)

## Build and install

Build from the repository root with the AmigaOS 4 cross-compiler.

```sh
make -C Drivers/Ethernet/RT2870
```

1. Install the matching `usb2.kmod` from the archive.
2. Copy `eth_RT2870.Class` and `eth_RT2870.Driver` from `usb2/Libs/USB2/` to
   `LIBS:USB2/`.
3. Copy `rt2870.bin` and `rt2870.licence` from
   `Drivers/Ethernet/RT2870/Firmware/` to `DEVS:Firmware/`. In the archive,
   both files are under `usb2/Devs/Firmware/`.
4. Install the manager and the libraries for your chosen security mode.
   See the [USB2WirelessManager guide](USB2WirelessManager.md).

The firmware comes from the
[Linux firmware repository](https://kernel.googlesource.com/pub/scm/linux/kernel/git/firmware/linux-firmware/+/refs/heads/main/rt2870.bin).

## Connect

```text
USB2WirelessManager "My Network" UNIT=0 WPA2
```

`WPA2` selects WPA2-Personal with CCMP. Use `WPA3` for WPA3-Personal
or `WPA` for legacy WPA-Personal with TKIP. The unit defaults to 0.
Use `usb2ethernet.device` and the unit shown in the serial log in your
TCP/IP configuration.

For a manual connection, start the TCP/IP interface after the manager
reports that it is connected. Leave the manager running while connected.
For saved profiles and automatic startup from TCP/IP, see the
[USB2WirelessManager guide](USB2WirelessManager.md#saved-profiles-and-startup).

## Validation and troubleshooting

Before the class conversion, testing on an AmigaOne X5000/20 exercised WPA2-Personal data
transfer and verified DHCP address assignment with WPA3-Personal and
legacy WPA-Personal.

During initialization, the serial log reports the MAC/BBP revision,
EEPROM station address, MCU firmware readiness, and the baseband revision.
Omit the security option to scan for an SSID. Add `AUTH` to test 802.11
authentication or `ASSOCIATE` to test WPA2 association and receipt of its
first handshake message. These checks finish before password entry.
