# RTL8152 USB Ethernet

`usb2rtl8152.device` is an experimental SANA-II driver for the Realtek RTL8152
wired USB Ethernet adapter. It matches USB vendor and product ID `0bda:8152`
and exposes a 1500-byte Ethernet payload MTU.

## Build and install

Build from the repository root with the AmigaOS 4 cross-compiler.

```sh
make -C Drivers/Ethernet/RTL8152
```

1. Start AmigaOS 4 with `usb2.device` loaded.
2. Copy `Drivers/Ethernet/RTL8152/bin/usb2rtl8152.device` to
   `DEVS:Networks/`. In the distribution archive, the file is at
   `usb2/Devs/Networks/usb2rtl8152.device`.
3. Connect the USB adapter and an Ethernet cable. Select
   `usb2rtl8152.device`, unit `0`, in your TCP/IP stack and configure the
   interface for your network.

## Validation

The AmigaOS 4 cross-build succeeds. Link detection, packet transmission and
reception, and recovery after USB detach still need testing on a physical
adapter.
