# RTL8152 USB Ethernet

`eth_RTL8152.Driver` is an experimental USB class driver for the Realtek RTL8152
wired USB Ethernet adapter. It matches USB vendor and product ID `0bda:8152`
and exposes a 1500-byte Ethernet payload MTU.

## Build and install

Build from the repository root with the AmigaOS 4 cross-compiler.

```sh
make -C Drivers/Ethernet/RTL8152
```

1. Install the matching `usb2.kmod` from the archive.
2. Copy `eth_RTL8152.Class` and `eth_RTL8152.Driver` from `usb2/Libs/USB2/` to
   `LIBS:USB2/`.
3. Boot the updated stack and connect the adapter and an Ethernet cable.
   Configure `usb2ethernet.device` in TCP/IP using the unit reported in the
   serial log. The first adapter normally gets unit 0.

## Starting TCP/IP at boot

The RTL8152 class loads during USB Full Boot. If the network script can run
before the adapter registers, install `USB2WaitEthernet` from the archive's
`Tools` directory in `C:` and run this command just before bringing up the
RTL8152 interface.

```amiga
C:USB2WaitEthernet UNIT=0 RTL8152 TIMEOUT=15
```

Use the same unit number as the TCP/IP interface configuration. The command
returns 0 as soon as that unit is registered by the RTL8152 driver, or 5
after the timeout. Gate the existing interface startup with `IF NOT WARN`
if it should run only when the adapter is ready. If the serial log never
shows `0BDA:8152`, test the adapter directly on the X5000 to check USB
detection.

## Validation

The AmigaOS 4 cross-build succeeds. Link detection, packet transmission and
reception, and recovery after USB detach still need testing on a physical
adapter.
