# RTL8152 USB Ethernet

`eth_RTL8152.Driver` is an experimental USB class driver for Realtek wired
USB Ethernet adapters. It matches vendor-specific interface 0 and exposes
a 1500-byte Ethernet payload MTU.

| USB IDs | Chip family | Chip revisions |
| --- | --- | --- |
| `0BDA:8152`, `0BDA:8050` | RTL8152 | `0x4C00`, `0x4C10` |
| `0BDA:8153`, `0BDA:8053` | RTL8153 | `0x5C00`, `0x5C10`, `0x5C20`, `0x5C30` |
| `0BDA:8153`, `0BDA:8053` | RTL8153B | `0x6000`, `0x6010` |

The same USB ID can be used by newer silicon. The serial log reports the
chip revision and reports unsupported revisions before registering a
network unit.

## Build and install

Build from the repository root with the AmigaOS 4 cross-compiler.

```sh
make -C Drivers/Ethernet/RTL8152
```

1. Install the matching `usb2.kmod` from the archive.
2. Copy `eth_RTL8152.Class` and `eth_RTL8152.Driver` from `usb2/Libs/USB2/` to
   `LIBS:USB2/`.
3. Boot the updated stack and connect the adapter and an Ethernet cable.
   Configure `usb2ethernet.device` in TCP/IP using the unit reported in the
   serial log. The first adapter normally gets unit 0.

## Validation

The AmigaOS 4 cross-build succeeds. These results were reported on an
AmigaOne X5000/20 with driver 1.14.

| Adapter | Test | Result |
| --- | --- | --- |
| RTL8152 (`0BDA:8152`, revision `0x4C10`) | Start from full power-off | Works |
| RTL8152 (`0BDA:8152`, revision `0x4C10`) | Cold reboot | Fails to enumerate |
| RTL8152 (`0BDA:8152`, revision `0x4C10`) | Warm reboot | Fails to enumerate |
| RTL8152 (`0BDA:8152`, revision `0x4C10`) | Plug in or replug | Works |
| RTL8153 (`0BDA:8153`, revision `0x5C20`) | Tested setup | No problems reported |

The RTL8152 reboot failure occurs during USB enumeration, before the
Ethernet driver runs. Other chip revisions and the `0BDA:8050` and
`0BDA:8053` USB IDs still need hardware validation.
